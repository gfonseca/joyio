# Gestão do projeto

Esta pasta concentra planejamento, backlog e prompts de execução do JoyIO.

## Documentos

- [Melhorias.md](Melhorias.md): visão curta do backlog por prioridade;
- [GESTAO_PROJETO.md](GESTAO_PROJETO.md): roadmap, marcos, dependências, riscos e critérios de entrega;
- [PROMPTS_ROADMAP.md](PROMPTS_ROADMAP.md): prompts prontos para executar cada épico;
- [PROMPT_DESENVOLVIMENTO.md](PROMPT_DESENVOLVIMENTO.md): especificação histórica que originou o projeto.
- [FASE_0.md](FASE_0.md), [FASE_1.md](FASE_1.md), [FASE_2.md](FASE_2.md) e [FASE_3.md](FASE_3.md): histórico e contratos das fases entregues.

## Fluxo recomendado

1. Consulte o item ativo em `Melhorias.md`.
2. Leia o marco correspondente em `GESTAO_PROJETO.md`.
3. Execute somente o prompt daquele marco em `PROMPTS_ROADMAP.md`.
4. Mantenha apenas uma tarefa em andamento.
5. Atualize backlog e estratégia ao concluir ou alterar uma decisão.

Documentação de usuário permanece no [README principal](../../README.md). Fases, decisões arquiteturais e benchmarks permanecem nas demais áreas de documentação técnica.
